# BROKERSHUB

Compliance for Australian mortgage and finance brokers, built to grow into brokerage operations.

This repo is the marketing site (Next.js, Tailwind 4, GSAP, Lenis), styled to match REAHUB and WHSCOMPLY.

```bash
npm install
npm run dev
```

Demo requests currently go to the address in `src/lib/site.ts` (`CONTACT_EMAIL`).
